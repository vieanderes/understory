# Exporting your data

You can download a copy of everything in your workspace.

## Start an export

Go to Settings, then Data, and select "Export workspace". Choose CSV for spreadsheets or JSON for developers. Large workspaces can take up to an hour. We email you a download link when the export is ready.

## What the export contains

The export includes projects, tasks, comments and file metadata. Attached files are listed with their names and sizes but are not included; download them from each project. The download link expires after seven days.

## Scheduled exports

On the Business plan you can schedule a weekly export to cloud storage. Set this up under Settings, Data, Scheduled exports.
